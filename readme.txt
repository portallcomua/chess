Повнофункціональна шахова платформа з підтримкою PWA, 8 унікальними дизайнами дошки, ШІ-тренером та монетизацією.

== Description ==

«Шахи проти ШІ» — це сучасна шахова платформа для WordPress з підтримкою прогресивних веб-додатків (PWA), 8 темами оформлення дошки, інтелектуальним ШІ-тренером, лімітами підказок та монетизацією.

= Основні можливості: =
* **8 ексклюзивних дизайнів дошки** з мініатюрами та функцією збільшення (Zoom) на ПК та смартфонах.
* **Режими гри:** Шахи проти ШІ, локальна гра на 2 гравців, онлайн-гра P2P (WebRTC).
* **Повноцінна підтримка PWA:** кнопка «Створити іконку» для встановлення на робочий стіл або смартфон.
* **ШІ-тренер:** аналіз позиції, підсвічування ходу та тактичні пояснення.
* **Окремий облік шахістів:** гравці реєструються у власній таблиці та не отримують доступу до адмінки сайту.
* **Керування та монетизація:** панель адміністратора у WordPress для керування лімітами підказок, цінами та статусами FREE / PRO.
* **Розсилка email:** можливість розсилати новини та анонси турнірів зареєстрованим шахістам.
* **Два шорткоди:** `[wp_chess_pwa]` для самої гри та `[wp_chess_pwa_guide]` для окремої сторінки інструкцій.

== Installation ==

1. Завантажте папку `wp-chess-pwa` у директорію `/wp-content/plugins/` (або завантажте zip через панель плагінів WordPress).
2. Активуйте плагін через меню «Плагіни» у WordPress.
3. Перейдіть до меню «Шахи проти ШІ» в адмінці WordPress для налаштування цін та лімітів.
4. Додайте шорткод `[wp_chess_pwa]` на сторінку гри, а `[wp_chess_pwa_guide]` — на сторінку «Як грати».
